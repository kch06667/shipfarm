# 쉽팜 — 작은 발걸음으로 시작하는 목장

옛 쉽팜 웹판 자료를 참고한 **개인 목장 시안 05**입니다. 아기양을 돌보고, 작물을 키우고, 양털을 팔며 새로운 양과 이웃을 만나는 오프라인 웹게임입니다. NFT·지갑·토큰·레이싱·유료 결제는 없습니다.

**원작 전체의 복원본은 아닙니다.** 원작에서 확인한 이름·조건·작물 수치와 새로 만든 이야기·규칙을 [설계 문서](docs/design.md)에 구분했습니다. 성체 이미지는 메타랜드 공개 도감의 외형 참고 자료이며, 원본 애니메이션을 복구한 것은 아닙니다.

다음 프로젝트에서 이어갈 작업은 **[인수인계·남은 작업 목록](docs/HANDOFF.md)**에 정리했습니다.

## 바로 플레이

[index.html](index.html)을 브라우저에서 여세요. 이미지와 코드를 모두 내장해 설치나 외부 통신 없이 실행됩니다. 브라우저별 `file://` 저장 차이를 피하려면 이 폴더에서 다음 명령으로 실행하고 <http://127.0.0.1:8000>을 여세요.

```sh
npm start
```

Node가 없으면 `python3 -m http.server 8000 --bind 127.0.0.1`로도 실행할 수 있습니다. 게임 실행 자체에는 npm 의존성 설치가 필요 없습니다.

진행은 **현재 브라우저에 자동 저장**됩니다. 설정의 **목장 파일로 저장 / 저장한 목장 불러오기**로 다른 기기에 옮기거나 가족에게 진행 파일을 전달할 수 있습니다. 실시간 공동 목장이나 계정 기능은 없습니다. 초기화와 파일 복원은 게임 안에서 확인한 뒤 실행합니다.

## 지금 할 수 있는 것

- **아기양 첫 수업**: 이름 짓기 → 쓰다듬기 → 우유 → 낮잠 → 성장 → 심기·수확 → 먹이 → 첫 양털. 첫 낮잠은 6초, 첫 작물은 12초입니다.
- **살아 있는 목장**: 양의 산책·풀 뜯기·휴식·먹이 이동·씻기·털 깎기, 포만감·청결·털 성장, 재접속 시 최대 2시간 생활 경과 반영.
- **양 10종, 외형 31가지**: 플레인·슈크림·플레임·천사·악마·쇼트·마린·해적·인형·마녀. 기본양 9색, 슈크림양 8색, 플레임양 7색을 골라 입양합니다. 색상은 성체가 되면 나타납니다.
- **작물 8종**: 원작 재배 시간·수확량, 종류별 그림과 성장 표시, 빈 밭 모두 심기·모두 수확.
- **먹이 창고와 양의 부탁**: 수확한 작물을 종류별로 보관하고 원하는 먹이를 골라 줍니다. 기존 저장의 먹이는 혼합 먹이로 보존합니다. 원하는 먹이 세 번 주기 부탁도 추가했습니다. 먹이 효과와 보너스는 시안용입니다. [모바일 창고](docs/preview-food-pantry-mobile.png)
- **수확 기한과 부패**: 다 자란 뒤 수확 가능 시간이 지나면 썩습니다. 접속하지 않은 시간도 계산하며, 썩은 작물은 먹이로 얻지 못하고 쭉정이를 치워야 합니다. 캬라멜팝콘은 재배 1분 + 수확 가능 1시간 30분입니다.
- **이야기와 반복 부탁**: 성냥팔이 소녀 이후 메에메에엘의 시험·수상한 남자·기우제·보물찾기·새로운 발명. 뒤의 다섯 이야기는 각각 세 장입니다.
- **양털 장터**: 종류별 양털 보관, 1묶음·5묶음·전체 판매. 첫 튜토리얼 수확만 바로 정산합니다.
- **쉼터**: 풀밭 6마리와 별도로 6 → 12 → 24마리까지 쉬는 자리 확장. 상태를 보존하며 옮기고, 풀밭이 가득 차면 친구끼리 교대합니다.
- **NPC 이웃 마을**: 미셸·켈리·케이티의 목장 방문. 이웃마다 하루 세 가지 도움, 한국 시간 자정 기준 갱신.
- **목장 앨범**: 수확·판매·이웃 도움·수집 등 여덟 가지 기록과 한 번씩 받는 선물.
- **꾸미기와 풍경**: 꽃밭·새집·버섯 조명·벤치 배치, 낮·살구빛 노을·별빛 저녁 선택.
- **스프링 쉽**: 꾸미기에서 설치하면 양이 스스로 찾아가 놉니다. 장식을 눌러 선택한 양을 보낼 수도 있습니다. 2011년 웹판 리뷰를 참고해 새로 만든 그림과 모션입니다.
- **모바일·접근성**: 일곱 메뉴의 작은 화면 배치, 키보드 포커스, 이름 문자 이스케이프, 기기의 동작 줄이기 설정 지원.

양 도감에서 조건을 확인할 수 있습니다. 슈크림양은 레벨 10, 쇼트양은 30, 마녀양은 70부터 열립니다. 나머지 특별한 양은 이야기를 마쳐야 합니다. 새로운 친구는 모두 아기양으로 입양됩니다.

## 개발과 검증

게임 코드는 `src/game.js`, 작물 부패는 `src/crop-life.js`, 놀이기구는 `src/farm-toys.js`, 먹이 재고·요청은 `src/food-pantry.js`, 다음 행동 안내·밭 정리는 `src/play-guide.js`, 스타일은 `src/style.css`, 화면 골격은 `src/shell.html`, 내장 이미지는 `src/assets.json`에서 수정합니다. `index.html`은 생성된 배포 파일입니다.

```sh
npm ci
npx playwright install chromium
npm run build
npm test
```

브라우저 검사는 `CHROMIUM_PATH`, 시스템 `/usr/bin/chromium`, Playwright 설치 Chromium 순으로 사용합니다. 테스트용 서버는 검사 중에만 열리고 종료 시 닫힙니다. 게임 빌드는 표준 Node 모듈만 사용합니다.

열 개 브라우저 시나리오에서 기존 진행·저장·모바일 배치와 작물 부패, 쭉정이, 놀이기구, 먹이 재고와 요청까지 검증합니다. 자세한 결과는 [검증 기록](docs/validation.md)을 참고하세요.

시안 05 후속 개선: 일반 양털을 처음 모으면 목장에서 판매 안내를 보여 줍니다. 마을을 켜 둔 채 한국 시간 자정을 넘기거나 다른 탭에서 돌아오면 이웃 도움 목록이 갱신됩니다.

목장 아래 **우리 목장, 다음 한 걸음**에서 수확·돌봄·먹이 준비·판매와 다음 해금 이야기를 찾을 수 있습니다. 먹이가 부족하면 1분짜리 캬라멜팝콘을 심어 보세요. 모든 밭이 오래 걸리는 작물로 찼다면 자라는 밭을 눌러 **1분 작물로 바꾸기**를 선택할 수 있습니다. 확인하면 기존 작물의 성장은 사라지며, 보상 없이 새로 재배합니다. [모바일 진행 안내](docs/preview-play-guide-mobile.png)

## 아직 남은 복원 범위

초밥양·미스테리 양상자·얼짱양·차도양·일부 천사양과 이벤트 양, 원작의 전체 색상·퀘스트·맵·애니메이션은 아직 구현되지 않았습니다. 정확한 원본 에셋과 서버 규칙도 확보하지 못했습니다. 교배·플레이어 간 교역·실시간 가족 공유는 포함하지 않았습니다.

[원작 조사와 구현 근거](docs/original-game-research.md)에 2011년 리뷰·작물 표·현재와 다른 규칙·다음 조사 순서를 기록했습니다. 기존 저장의 작물도 원래 수확 시각을 기준으로 부패하므로 오래 비운 목장에는 쭉정이가 남을 수 있습니다.
