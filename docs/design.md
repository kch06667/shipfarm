# 쉽팜 인 슈가랜드 — 개인 목장 시안 01

최신 후속 변경: 목장에 상태별 다음 행동 안내를 추가했다. 돌봄·수확·먹이 준비·판매 중 필요한 행동과 다음 해금 이야기를 최대 네 카드로 표시한다. 저장 필드를 추가하지 않고 현재 상태에서 계산한다.

튜토리얼 이후 자라는 밭을 누르면 비우기 또는 1분 캬라멜팝콘으로 바꾸기를 선택할 수 있다. 기존 작물과 경과 시간이 사라짐을 확인한 뒤 실행하고, 먹이·코인·경험치·수확 횟수는 지급하지 않는다. 확인 중 작물이 다 자랐다면 삭제하지 않고 수확을 안내한다. 빈 밭·먹이·코인이 모두 없는 장시간 대기를 피하기 위한 새 시안 규칙이며 원작에서 확인된 기능은 아니다.

목표: 네이버 웹판의 양 수집·돌봄·농사·이야기를 가족끼리 즐길 수 있는 웹게임으로 재현한다. NFT, 지갑, 토큰, 블록체인, 레이싱, 베팅, 유료 결제는 설계에서 제외한다. 메타랜드 자료는 정지 이미지의 외형 참고에만 사용한다.

## 조사 결과와 근거

- 제목: [쉽팜 인 슈가랜드]양 종류
- 게시일: 2012-02-18. 본문 직접 확인.
- 확인: 레벨별로 보이는 양이 다름. 공모전양·플레인·슈크림·플레임·천사·악마·초밥·쇼트·이벤트 양 분류. 글에 공모전양은 별 5개, 밥통 150으로 기록. 쇼트양의 긴 먹이 간격, 씻기 필요, 시기 한정 양에 관한 설명이 있다.

- 영상: 사용자가 업로드한 약 3분 27초 모바일 for Kakao 튜토리얼.

- 교역양 표: 등급·최저가·최고가라는 구성은 보인다. 버전과 정확한 시세 결정 공식은 미확인이다.

- 정지 PNG를 확보한 것이며 원본 애니메이션·게임 클라이언트·재배포 권한을 확보한 것은 아니다. 공개 배포 전 별도 확인이 필요하다.

## 화면 설계

1. **나의 목장**: 화면 대부분을 차지하는 비스듬한 2D 목장, 양과 밭 직접 선택, 하단 돌봄 도구. 베이지 패널·연두색 잔디·과자 나무로 따뜻한 분위기를 유지한다.
2. **양 도감**: 종류별 외형, 입양 가격, 해금 조건. 희귀도를 금융 자산처럼 표현하지 않는다.
3. **씨앗 상점**: 일반 작물 8종의 수확량·재배 시간·지속 시간을 비교하고 씨앗 선택.
4. **이야기**: 짧은 반복 부탁과 종류 해금으로 이어지는 연계 퀘스트. 원작 대사를 찾기 전에는 새로 쓴 문장을 원작 대사로 표시하지 않는다.
5. **향후 교역소**: 양을 고르고 외형·성장·등급을 살펴본 뒤 견적 확인과 확인 창을 거쳐 거래. 기존 시세표의 버전과 공식 검증 전에는 원작 시세를 재현했다고 주장하지 않는다.
6. **향후 꾸미기**: 타일·울타리·건물·장식을 격자 배치하고 회전/회수. 초기 시안의 배경은 고정이다.
7. **향후 가족 목장**: 가족별 저장과 방문. 원작의 이웃 의존 퀘스트는 혼자 플레이할 때 NPC 이웃으로 충족할 수 있게 한다. 이는 사용자 목표에 맞춘 의도적인 변경이다.

## 이번 시안의 실제 동작

- 양 선택, 쓰다듬기, 먹이 주기, 씻기, 털 깎기와 임시 판매 보상.
- 작물 선택·심기·타이머·수확. 첫 화면에 수확 가능한 밭 3개를 제공한다.
- 원작 일반 작물의 재배 시간과 수확량. 지속 시간은 표에 표시만 하며 시듦은 아직 구현하지 않는다.
- 부탁 3개 완료, 중복 보상 방지, 플레임램 해금, 최대 6마리 입양.
- 같은 브라우저의 localStorage 저장과 새로고침 복구.
- 설정에서 작물 즉시 성장 체험과 확인 후 초기화.
- 1440px 데스크톱과 390px 모바일 화면. 좁은 화면에서는 목장 영역을 가로로 스크롤한다.

## 확인되지 않은 규칙 / 의도적인 임시 값

- 레벨 10, 12,500코인, 먹이 36으로 시작하는 체험 상태.
- 먹이 5 소비, 포만감/털 25 증가, 양털 120코인, 경험치와 퀘스트 보상은 모두 임시 수치다.
- 작물 수확량을 먹이 재고로 변환하는 방식도 임시다. 원작 포만감·먹이 선호·밥통·섭취 간격 공식은 별도 조사해야 한다.
- 실제 성장 단계, 자율 이동, 여러 방향 애니메이션, 털 깎인 외형, 자연 포만감 감소, 청결도 감소, 쭉정이, 교역 공식은 미구현.
- ‘성냥팔이 소녀’ 해금은 원작 연계 퀘스트의 이름만 참고하고 시안용 세 부탁 완료로 대체했다. 원작 순서나 대사가 아니다.
- 천사양/악마양/쇼트양은 도감 표시만 제공. 상점 전체·캐시 상품·이벤트를 복원한 것은 아니다.
- 서버·계정·가족 공유·꾸미기 편집·교배·교역은 미구현이다.

## 다음 제작 순서

1. 이 화면의 목장 비중·색감·양 크기를 사용자와 맞춘다.
2. 정지 외형과 원본 애니메이션을 구분하고, 추가 원본 자료를 조사한다.
3. 원작의 밥통·먹이 간격·털 생산·성장 규칙을 근거별로 정리한다.
4. 작물 → 먹이 → 양 성장/털 → 코인 → 입양/꾸미기 흐름을 구현한다.
5. 장식 배치, 퀘스트 시나리오, 가족 저장/방문을 순차 확장한다.


## 시안 02 변경 — 모션·맵·아기양 튜토리얼

이 절은 위의 시안 01 기본 시작 상태를 대체한다. 기존 웹판 조사 출처는 유지한다.

### 모션

- 이동 위치와 방향, 현재 행동을 가진 작은 상태 머신으로 산책 → 쉬기/풀 뜯기/졸기를 반복한다.
- 이동 목적지는 집·연못·밭을 피한 잔디 공간으로 한정한다. 현재는 완전한 경로 탐색이나 양끼리의 충돌 회피까지 구현한 것은 아니다.
- 걸을 때 다리가 교차하고 몸이 살짝 들썩인다. 정지 상태에서도 호흡과 아기양 눈 깜빡임·귀 움직임이 있다.
- 쓰다듬으면 폴짝 뛰고 하트가 떠오른다. 씻기는 동작에는 흔들림·물방울, 먹기는 고개를 숙이는 동작, 낮잠에는 호흡과 Z 표시를 사용한다.
- 성체는 공개 PNG와 브라우저에서 만든 다리·몸통 변형을 조합한 모션이다. 원본 애니메이션을 복구한 것은 아니다.
- 아기양은 새로 그린 SVG이며 원본 아기양 스프라이트가 아니다. 모든 종류의 아기양은 현재 공통 외형이다.
- 모션은 화면 재렌더링에 위치가 초기화되지 않게 관리한다. 저장된 성장/수면 시각은 재접속 후 이어진다.
- 접근성: 동작 줄이기를 켜면 자율 산책과 반복 애니메이션을 중지하고, 먹이 반응은 목적지로 즉시 이동해 처리한다.

### 맵

- 크림과 과자층이 보이는 부드러운 지형, 줄기와 하이라이트가 있는 과자 나무, 지붕의 크림 장식과 창가 꽃, 작은 연못, 이정표, 연기, 나비와 꽃가루를 추가했다.
- 맵·양·밭 좌표를 같은 비율의 월드 안에서 배치한다. 모바일에서는 같은 월드를 가로로 이동해서 본다.
- 모든 배경 요소는 새로 제작한 SVG/CSS이다. 원작 맵 원본이 아니다.

### 튜토리얼과 저장

1. 아기양 이름 입력(최대 12글자, HTML로 해석하지 않음).
2. 쓰다듬어 성장 25%.
3. 우유를 주어 성장 65%.
4. 낮잠 6초 후 성체로 성장.
5. 캬라멜팝콘 심기. 첫 작물만 12초 체험 시간 적용.
6. 수확으로 먹이 5 확보.
7. 양이 밭 옆으로 걸어가 먹은 뒤 털 100%.
8. 첫 털 수확과 500코인 축하 선물로 마무리.

위 성장·먹이·퀘스트 수치는 새로 설계한 튜토리얼 값이며 원작의 사실로 주장하지 않는다. 완료 후 양 도감·씨앗 상점·이야기 메뉴를 연다. 초보자를 위해 완료 전에는 다른 메뉴로 길을 잃지 않도록 안내한다.

이전 저장의 양·재화·퀘스트를 보존하고 `version:2`로 이관한다. 기존 양은 성체로 유지하고 튜토리얼은 완료 처리한다. 새 저장만 아기양/레벨 1/2,000코인으로 시작한다. 초기화에는 확인 단계가 있다.

현재 한계: 자연 포만감·청결도 감소, 실제 성장 밸런스, 모든 종류의 새끼 외형, 털 깎인 원본 외형, 맵 편집과 교역은 여전히 후속 작업이다.

## 시안 03 — 매일 돌아오는 목장

### 생활 주기

- 튜토리얼을 완료한 성체의 포만감은 40초당 1, 청결은 90초당 1 감소한다.
- 포만감이 15 초과이고 청결이 20 초과인 동안 양털이 8초당 1 증가한다. 한 주기 안에서 임계점에 도달하면 그 시점까지만 생산 시간을 인정한다.
- 포만감·청결도·양털은 0~100으로 제한한다. 양을 잃거나 죽는 불이익은 없다.
- `lastTick`을 저장해 재접속 시 최대 2시간을 반영한다. 튜토리얼과 아기양은 자연 감소에서 제외한다.
- 이는 시안 밸런스이며 원작 서버의 공식을 복구한 값이 아니다.
- 쓰다듬기 모션은 계속 가능하지만 경험치 보상에는 10초 간격을 둔다.

### 조작과 상태 피드백

- 목장 위 ‘우리집 친구들’에서 양을 고르면 해당 양이 보이는 위치로 이동한다.
- 이동 중 양에 마우스를 올리면 잠깐 멈춰 선택하기 편해진다.
- 양 이름 옆 연필 버튼으로 수첩을 열어 포만감·청결·털 상태를 보고 이름을 바꿀 수 있다.
- 부족한 상태, 털 생산 정지 이유, 식사 중 상태를 하단에 표시한다.
- 튜토리얼의 ‘지금 할 일 찾기’는 해당 밭이나 행동 버튼으로 이동한다.
- 작물 8종마다 시안용 SVG 외형을 제작했다. 성장 단계를 나누고 진행 막대·수확 강조 표시를 추가했다. 원본 작물 스프라이트는 아니다.
- 씨앗 상점에서 선택 후 ‘목장에 심으러 가기’를 누르면 빈 밭을 찾는다. 긴 시간은 시간·분으로 표시한다.

### 목장 꾸미기

- 튜토리얼 후 목장 꾸미기에서 꽃밭(80코인), 새집(140), 버섯 조명(120), 벤치(180)를 네 지정 위치에 놓을 수 있다.
- 다른 장식으로 바꾸면 기존 장식의 코인을 반환한 후 차액을 반영한다. 회수하면 전액 반환한다.
- 장식은 저장·백업에 포함된다. 자유 격자 이동·회전·건물 편집은 후속 작업이다.

### 저장과 복원

- 기존 자동 저장에 10초 주기 및 페이지 종료 직전 저장을 보강했다.
- 설정에서 JSON 목장 파일을 다운로드하고, 다른 브라우저에서 파일로 불러올 수 있다.
- 복원 전 파일 크기·형식·수치·양/밭/퀘스트/튜토리얼/장식 구조를 검증한다. 잘못된 파일은 현재 목장을 바꾸지 않는다.
- 유효한 파일도 양 수와 코인을 보여 준 뒤 확인해야 덮어쓴다. 취소하면 현재 상태를 유지한다.
- 자동 서버 동기화나 가족 계정 기능은 아니다. 여러 기기에서 각각 진행하면 파일로 옮긴 시점의 기록을 기준으로 이어진다.

## 시안 04 — 튜토리얼 다음의 이야기

### 반복 부탁

- 튜토리얼 이후 켈리·미셸·케이티의 부탁 3개가 게시판에 표시된다.
- 여섯 템플릿(먹이 10개/20개 전달, 수확 2회/3회, 쓰다듬기 3회, 양털 수확 1회)을 순환한다.
- 행동형 부탁은 새로 받은 시점의 누적 통계를 기준으로 이후 행동만 인정한다. 먹이 전달은 보유 먹이를 실제로 차감한다.
- 완료 시 코인·경험치를 주고 다음 부탁으로 바뀐다. 고유 토큰으로 이전 완료 버튼의 중복 실행을 차단한다.
- 사이드바와 이야기 탭에 완료 가능한 부탁을 표시한다. 온라인 이웃이나 매일 접속이 없어도 진행할 수 있다.

### 세 장으로 구성한 두 연계 이야기

- 첫 성냥팔이 소녀 해금 이후 ‘메에메에엘의 시험’, ‘수상한 남자’를 시작할 수 있다.
- 각 이야기의 대화 → 부탁 수락 → 이후 행동 달성 → 보상 → 다음 대화 순서로 진행한다.
- ‘메에메에엘의 시험’: 쓰다듬기 3회 → 새 수확 3회 → 먹이 20개 전달 → 천사양 해금.
- ‘수상한 남자’: 양털 수확 1회 → 새 수확 2회 → 먹이 25개 전달 → 악마양 해금.
- 장 번호와 진행 여부를 저장하고, 완료할 때 기대 장 번호를 확인해 중복 보상을 방지한다.
- 원작 퀘스트 이름만 참고했다. 대사·목표·보상·연계 순서는 새로 각색한 시안이며 원작 복원 데이터가 아니다.
- 천사양 4,200코인·악마양 5,800코인으로 입양 가능하다. 이 가격은 시안용으로 도감에 표시한다. 새 양은 공통 아기양 외형으로 시작하며 성장 후 종류별 이미지로 바뀐다.
- 쇼트양은 여전히 후속 구현 대상이며, 레벨 조건 표시만으로 입양이 가능하다고 주장하지 않는다.

### 편의와 움직임

- 도감에 전체/입양 가능/미해금 필터와 현재 보유 마릿수를 추가했다.
- ‘모두 수확’은 현재 준비된 밭만 수확하고, 먹이·경험치·부탁 통계를 개별 수확과 같은 경로로 갱신한다.
- 양끼리 겹치면 작은 위치 보정으로 떨어지며 잔디 범위에 머문다. 낮잠 중이거나 식사 중인 양은 우선 고정한다.
- 이는 로컬 간격 보정이며 복잡한 장애물 경로 탐색은 아니다. 동작 줄이기 설정에서는 이 보정도 멈춘다.

### 저장

- 기존 저장에는 비어 있는 부탁·이야기 기록을 추가한다. 기존 양·재화·꾸미기를 유지한다.
- 백업 검사에 부탁 템플릿/토큰/기준치와 이야기 장 번호/수락 상태/기준치를 추가했다.

## 시안 05 — 수집·경제·쉼터·이웃의 연결

이 절은 이전 시안 설명 중 미구현이던 양털 창고와 추가 입양을 갱신한다. 원작 자체가 아닌 개인 플레이용 재구성이다.

### 양과 외형

기존 6종에 마린양·해적양·인형양·마녀양을 추가해 10종을 제공한다. 기본양 9색, 슈크림양 8색, 플레임양 7색과 다른 7종의 대표 외형을 합쳐 31개 성체 이미지다. 실제 원작 분류와 메타랜드 영문 이름의 대응은 잠정적이며, 특히 천사양 1/2의 정확한 구분은 미완료다. 아기양 그림은 모든 종에서 공통인 자체 SVG이며 성장 시 선택한 종·색상을 적용한다.

플레인 색상별 가격은 흰색·갈색 990, 회색·분홍색 1,100, 붉은색·하늘색 1,200, 노란색·파랑 1,800, 녹색 1,100이다. 슈크림은 흰색·갈색 1,400, 회색·분홍색 1,600, 붉은색·하늘색 1,900, 노란색 2,800, 파랑 2,300이다. 플레임은 흰색·노란색 2,000, 빨간색 2,300, 분홍색 3,000, 보라색 3,500, 금색 4,600, 어두운회색 8,400이다. 가격은 사용자가 제공한 웹판 상점 캡처를 옮겼고, 정지 그림은 공개 도감에서 비교한 외형을 사용한다. [전체 이미지 원본 URL](image-sources.csv)을 기록했다.

쇼트양은 레벨 30, 마녀양은 레벨 70을 해금 조건으로 유지했다. 두 양의 코인 입양 가격 9,000·18,000은 시안 설정이다. 원작 딸기 쇼트양의 캐시 가격을 복원한 값이 아니다. 천사 4,200, 악마 5,800, 마린 4,600, 해적 6,400, 인형 5,200 역시 시안 가격이며 도감에 표시한다.

### 양털과 플레이 반복

일반 털 깎기는 해당 양 종류의 양털 1묶음과 경험치 8을 주며, 코인은 장터에서 판매할 때 지급한다. 첫 튜토리얼은 기존 진행·보상을 유지해 양털 120코인을 즉시 정산한다. 판매가는 플레인부터 도감 순서대로 120/160/180/220/240/300/210/260/230/420 코인이다. 전부 새 밸런싱 값이며 색상별 가격 차이는 없다. 1묶음·5묶음·전체 판매는 실제 재고를 검사한 뒤 차감한다.

씨앗 무료·짧은 성장 체험·완만한 생활 주기는 기존 시안을 유지한다. 오래 기다리는 작물의 원작 시간도 유지하며, 설정의 작물 완성 도구는 계속 명시적인 체험 도구로 남는다. 밭의 ‘지속시간’ 의미가 확정되지 않아 시듦은 구현하지 않았다.

### 쉼터와 저장

풀밭은 6마리를 유지해 이동 공간을 확보한다. 별도 쉼터는 기본 6자리이며 1,200코인으로 12자리, 3,500코인으로 24자리까지 늘린다. 총 보유 가능 수는 풀밭을 포함해 최대 30마리다. 이 숫자와 가격은 시안 설정이다. 쉼터에선 생활 수치와 성장 시간이 정지한다. 먹는 중이거나 성장 낮잠 중인 양은 이동하지 못하며 풀밭에는 적어도 한 마리가 남는다.

각 양의 안정적인 `uid`를 저장해 이동·교대 시 인덱스가 바뀌어도 다른 양을 잘못 옮기지 않는다. 같은 이전 요청을 재실행해도 추가 이동·확장 비용이 발생하지 않는다. 교대 시 이미 지급된 먹이 효과를 유지하면서 이동 상태를 정리한다. 쉼터에서 나올 때 쉰 기간을 뒤늦게 차감하지 않는다.

저장 키 `shipfarm-concept-v1`, 저장 버전 2를 유지하고 선택적 필드를 추가한다: `woolStock`, `barn`, `neighborHelp`, `album`, `discovered`, `nextSheepId`, `light`, 양의 `uid`·`variant`, 통계 `help`·`sold`. 이전 v1/v2 파일에 새 필드가 없어도 초기화해 이어간다. 파일 가져오기는 범위·배열 크기·종류·색상·중복 ID·쉼터 상태 등을 검사하며 적용 전 요약을 보여 준다.

### 마을·이야기·앨범

NPC 이웃은 미셸·켈리·케이티 세 명이다. 실제 이용자나 원작 서버의 목장이 아니다. 이웃별 세 가지 도움은 각각 80코인·12경험치를 주며, 한국 시간 자정 기준 날짜를 저장해 하루 한 번만 지급한다. 기기 시간을 앞당길 수 있는 오프라인 시안이며 서버 검증을 제공하지 않는다. 날짜를 뒤로 돌리거나 같은 날 다시 불러와도 이미 완료한 보상을 중복 지급하지 않는다.

새 연계 이야기 세 가지도 원작의 제목·해금 종만 참고해 세 장으로 새로 썼다.

| 이야기 | 1장 | 2장 | 3장 | 해금 |
| --- | --- | --- | --- | --- |
| 기우제 | 새 이웃 도움 3번 | 먹이 20개 | 새 수확 3번 | 마린양 |
| 보물찾기 | 새 이웃 도움 3번 | 새 양털 수확 2번 | 새 판매 3묶음 | 해적양 |
| 새로운 발명 | 새 쓰다듬기 4번 | 새 양털 수확 2번 | 먹이 30개 | 인형양 |

행동 목표는 수락 시점부터 센다. 먹이는 실제 보유량을 검사하고 완료 시 차감한다. 앨범은 첫 수업·수확 10번·양털 10번·도움 9번·판매 20묶음·5종 수집·반복 부탁 20번·쉼터 최종 확장 등 여덟 가지 기록이며 보상은 각 한 번만 준다.

### 배포와 남은 과제

원본 파일을 `src/`로 분리했고 `node scripts/build.cjs`가 외부 의존성이 없는 단일 HTML을 만든다. 결과물은 1MB 미만이며 이미지·코드를 내장한다. `npm start`는 로컬 호스트만 기본으로 사용한다. 게임에 분석·추적·외부 API 요청은 없다.

아직 원작 완전 복원은 아니다. 초밥양, 미스테리 양상자, 얼짱양, 차도양, 천사양 세부 구분, 이벤트 양과 모바일 전용 종, 전체 원작 퀘스트·맵·애니메이션이 남았다. 실제 교배·플레이어 교역·공유 계정·실시간 가족 서버도 없다. 그림의 사용 허락을 확보한 것은 아니며 공개 도감 자료를 개인 시안의 외형 참고로 기록했다.
