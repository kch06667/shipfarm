# 시안 검증

시스템 Chromium과 Playwright로 실제 HTML을 로컬 HTTP 서버에서 실행했다.

통과한 동작:
- 양 3마리 초기 표시, 쓰다듬기 누적
- 털 깎기 후 보상과 재실행 방지
- 준비된 밭 3개 수확 후 먹이 36 → 61
- 먹이 주기 후 먹이 61 → 56
- 씨앗 선택, 심기, 미래의 수확 시각 저장
- 부탁 3개 보상, 플레임램 해금과 입양
- 새로고침 후 양 4마리·해금 상태 유지
- 시안 도구로 작물 수확 가능 상태 전환
- 390px 모바일에서 문서 가로 넘침 없음
- 확인 후 초기화 시 원래 양 3마리와 12,500코인 복구
- 브라우저 JavaScript 오류 없음

스크린샷: 1440×1000 데스크톱, 390×844 모바일 기준. 저장된 화면은 기능 체험 중 상태도 포함한다.

미검증: 다른 브라우저, 실제 다중 사용자 환경, 장기간 타이머 운용, 원작과의 규칙 동일성. 원본 서버·게임 실행 파일을 확보한 것은 아니다.

## 시안 02 검증

`tests/browser-smoke.cjs`로 다음을 실제 Chromium에서 확인했다.

- 새 저장에서 아기양 1마리 시작과 실제 위치 변화(자율 이동).
- `<솜솜>` 같은 이름을 HTML로 해석하지 않고 그대로 표시.
- 쓰다듬기/우유/낮잠 행동과 해당 모션 상태.
- 낮잠 중 새로고침 후 성장 완료, 다음 튜토리얼 단계 복원.
- 첫 작물의 실제 12초 타이머 후 수확.
- 먹이 5 소비, 밭 옆 이동과 식사 완료, 첫 털 수확으로 튜토리얼 완료.
- 새로운 입양은 아기양으로 시작, 새로고침 후 유지.
- 이전 v1 저장의 재화·양·레벨·퀘스트 유지 및 v2 변환.
- `prefers-reduced-motion: reduce`에서 자율 이동 정지.
- JavaScript 오류 없음.
- 390px 화면에서 문서 가로 넘침 없음. 맵 내부만 가로 스크롤.
- 별도 레이아웃 검사: 데스크톱에서 모바일로 크기 변경 시 선택한 양을 화면 중앙으로 이동.

`preview-v2-baby.png`는 실제 첫 시작 화면이다. `preview-v2-desktop.png`와 `preview-v2-mobile.png`는 여러 모션·작물을 함께 볼 수 있도록 구성한 시연 상태이며 기본 시작 상태가 아니다.

## 시안 03 검증

추가 검사: `node tests/polish-smoke.cjs`

- 시간 경과에 따른 포만감·청결·양털 변화, 성장 임계점, 오프라인 2시간 제한과 양 보존.
- 장식 구입·교체·회수 시 코인과 배치 상태.
- 양 이름의 안전한 표시와 연속 쓰다듬기 경험치 중복 방지.
- 작물 8종의 서로 다른 SVG, 선택·심기·진행 막대.
- 실제 파일 다운로드로 백업 생성, 잘못된 파일 거부, 복원 취소, 확인 후 복원과 새로고침 유지.
- 모바일 가로 넘침 없음, 실행 중 동작 줄이기를 켜면 산책 정지.
- JavaScript 오류 없음.

기존 `browser-smoke.cjs`도 함께 사용하여 아기양 튜토리얼과 이전 저장 이관을 회귀 검증한다. 테스트용 레거시 저장은 종료 자동 저장에 덮어쓰이지 않도록 다음 로드의 초기화 시점에 주입한다.

`preview-v3-desktop.png`, `preview-v3-crops.png`, `preview-v3-mobile.png`는 여러 장식과 작물을 함께 볼 수 있도록 구성한 시연 상태다. 새 저장은 아기양 한 마리로 시작한다.

## 시안 04 검증

검사: `node tests/progression-smoke.cjs`

- 첫 세 부탁의 보상과 플레임램 해금 유지.
- 먹이 전달 실제 차감, 새 부탁 기준치 생성, 이전 토큰의 중복 수령 거부.
- 천사양 연계 3장과 악마양 연계 3장을 UI로 수락·진행·완료.
- 이전 장 완료 호출의 중복 보상 거부.
- 모두 수확 시 여러 밭의 수확 통계 증가.
- 천사양·악마양 해금 후 아기양 입양, 새로고침 후 이야기 기록 유지.
- 새 진행 상태의 백업 검증 통과 및 잘못된 부탁 템플릿 거부.
- 도감 필터, 겹친 양의 간격 보정과 잔디 범위 유지.
- 390px 이야기 화면 가로 넘침 없음, JavaScript 오류 없음.

기존 `browser-smoke.cjs`, `polish-smoke.cjs`도 함께 실행했고 모두 통과했다.

`preview-v4-stories.png`, `preview-v4-collection.png`, `preview-v4-mobile.png`는 검증 과정에서 이야기를 완료한 상태의 화면이다.

## 시안 05 검증

실행: `npm test` — 빌드 후 다섯 Chromium 시나리오를 순서대로 실행한다. `/usr/bin/chromium`을 사용했고, 다른 환경에서는 `CHROMIUM_PATH` 또는 Playwright Chromium을 사용할 수 있다.

- 기존 `browser-smoke`, `polish-smoke`, `progression-smoke`: 아기양의 실제 6초 성장·첫 12초 작물·먹이 이동, 이전 저장 이관, 기존 이야기, 생명 주기·백업·장식의 회귀 검사.
- `homestead-smoke`: 양털 보관·판매 비용·재고 부족·중복 판매 방지, 쉼터 이동과 교대·상태 정지·확장 비용·중복 요청·재접속, NPC 도움의 하루 제한·시간 역행, 새 세 이야기의 목표 부족·기준점·중복 보상, 레벨 30/70, 일괄 심기, 앨범 중복 선물 방지, 잘못된 새 저장 필드 거절.
- `variants-smoke`: 실제 UI로 색상 선택·가격 지불·아기양 성장·정확한 성체 이미지, 쉼터·재접속 후 색상 보존, 잘못된 색상 거절, 새 종의 자율 이동, 낮/밤 배경, 모바일 색상 대화상자.
- 390px 화면에서 일곱 탭의 문서 가로 넘침을 검사했다. 별도의 동작 줄이기 설정과 일반 애니메이션 환경을 모두 사용했다.
- 브라우저 콘솔의 미처리 오류는 각 시나리오 끝에서 검사한다. 스크린샷은 기능 확인용 진행 데이터를 사용하며 시작 데이터가 아니다.

시안 05 스크린샷: `preview-v5-farm.png`, `preview-v5-night.png`, `preview-v5-market.png`, `preview-v5-barn.png`, `preview-v5-village.png`, `preview-v5-mobile.png`, `preview-v5-colors.png`, `preview-v5-colors-mobile.png`.

검사 범위 밖: 실제 Android/iOS 기기, 장기 수 주 플레이, 서버 동기화, 모든 원작 콘텐츠의 정확성. 원작 자료로 검증되지 않은 공식과 이야기 대사는 재구성이다.

최종 결과: `npm test`의 다섯 시나리오 모두 통과했다. 추가로 로컬 실행기의 200/404 응답을 확인했다. 이 환경의 관리형 Chromium은 `file://` 탐색을 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단하므로 직접 파일 열기는 검증하지 못했다. 로컬 HTTP 실행을 권장한다. 배포 HTML은 675,075바이트이며 JavaScript 구문 검사도 통과했다.

대체 확인: 로컬 HTTP에서 문서를 연 뒤 Chromium 네트워크를 오프라인으로 전환했다. 그 상태에서 내장 이미지 31개 디코딩과 아기양 이름 짓기·저장을 통과했고, 외부 HTTP 요청은 0건이었다.
